### AcneScan AI — Acne Detection & Severity Visualization

A web application that detects acne lesions in facial photos
and presents severity categories based on the Hayashi Criteria.

- Browser-based photo uploads connected to a FastAPI inference backend.
- YOLOv11 lesion detection with lesion counts.
- Results displaying Mild, Moderate, Severe, or Very Severe categories.
- Hayashi scale visualization to explain the classification.

**Stack:** React · JavaScript · Python · FastAPI · YOLOv11

[Frontend](https://github.com/Dylm54/TA_Frontend) ·
[Backend](https://github.com/Dylm54/TA_Backend)
